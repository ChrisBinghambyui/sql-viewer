# Overview

Compared to some of the other programming applications and languages, I have found MySQL to be easy to understand, but difficult to approach for the people I've tried to share it with. That's a shame, because databases can be incredibly useful, and even a barebones, surface level knowledge can allow a user to organize and read data in lots of useful formats.

That's why I wanted to build a browser that can help people put together queries and read databases without technical knowledge. The program lets users build queries through keywords. This query is then read and interpreted, and the results are returned. If a user wants more info on a specific thing, clicking on it will bring up everything it's connected to (still a WIP).

[Software Demo Video](https://youtu.be/3WNqGCbT3jk)

# Relational Database

Included is a sample database that I've built out for a game I'm working on. There are multiple connected tables from things like levels, abilities, enemies, and weapons. However the browser should be able to handle any database you throw at it.
